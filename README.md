# Minha Biblioteca

App pessoal para catalogar livros, acompanhar leituras, guardar citações e
controlar a lista de compras. Roda inteiramente no navegador — os dados
ficam no seu dispositivo (IndexedDB), sem servidor e sem conta.

## Usar no celular

Abra o link do GitHub Pages no Safari (iPhone) e toque em
**Compartilhar → Adicionar à Tela de Início** para instalar como app.

## Backup

Use a aba "Backup" dentro do app para exportar/importar seus dados. Como o
iOS pode limpar dados de sites sem uso frequente, vale exportar de vez em
quando.

## Rodar localmente

```
node server.js
```

Depois acesse http://localhost:5173
